# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's private vulnerability reporting for this repository (the **Report a vulnerability** link on the Security tab) to send a confidential report to the maintainers. Include affected versions or commit, impact, reproduction steps, and any suggested mitigation. Do not include real user data or live credentials.

If private vulnerability reporting is unavailable, contact the repository owner privately through their GitHub profile and identify the message as a security report. Please allow maintainers reasonable time to investigate and prepare a fix before public disclosure.

## Scope

Reports involving authentication, authorization, media access, upload processing, secrets, or deployment configuration are in scope. Do not access or modify data that is not yours while validating a report.
